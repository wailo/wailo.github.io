# OAA lesson generation rules

These rules apply to lessons derived from `ppl_05_e2.pdf`.

1. Prefix every generated lesson filename with `easa_`.
2. When repositioning the C172, use a target speed no greater than 105 knots. Repositioning
   higher speed may fail; use 105 knots as the highest safe target unless a lower speed is required.
2. When repositioning the C172, use a target altitude no greater than 5000 ft. Repositioning
   higher altitude may fail; use 5000 ft as the highest safe target unless a lower altitude is required.
